\section{Experimental Setup}
\label{sec:experiments}

\subsection{Controlled local Push-T}

Push-T is a contact-rich planar manipulation task \citep{florence2022ibc}. The controlled local protocol uses the frozen action-conditioned JEPA world model and 100 fresh cloned anchor states. Each state has an identical 81-action angular reference family at horizon H6; finite-grid scalar CEM makes four rounds of 16 queries plus a final-mean query (65 total). An action-blind \texttt{StandardScaler}+ridge readout ($\alpha=100$) consumes terminal pooled visual and proprioceptive latents. Its regularization is selected from five values by five-fold anchor-grouped development Spearman correlation and it is fit on 80 development anchors using only encoded true futures and simulator costs. Exact state restoration, action alignment, temporal indexing, and deterministic replay were validated before attribution. This restricted local action slice enables auditable candidate matching; it is \emph{not} the official Push-T planner.

The diagnosis, metric repair, and inference-precision control were fixed before repair computation. The repair replaces latent L2 with the frozen readout under matched queries and search seeds. The control changes predictor inference from BF16 to FP32 while retaining latent L2; it tests numerical precision only, not a retrained or architecturally improved predictor. Diagnosis and repair reuse the same 100 final anchors, so agreement in effect size is an internal prospective consistency check rather than independent replication.

\subsection{Disjoint-state Wall validation}

Wall uses the frozen DotWall environment/model interface and a controlled one-dimensional, two-segment waypoint family: 41 reference candidates and the same fixed 11 planner queries for every method. Development (60), diagnosis (80), and repair-validation (80) states have disjoint seeds, cloned states, and layouts. An action-blind \texttt{StandardScaler}+ridge readout ($\alpha=10$) uses terminal goal-delta, absolute-delta, and squared-delta features from visual and proprioceptive latents; regularization is selected by five-fold anchor-grouped development Spearman correlation using true futures only.

The protocol was frozen before diagnosis, and the repair choice was recorded while the repair cache was absent. The predictor-only repair freezes both encoders and fine-tunes the predictor on 48 training anchors, selecting one checkpoint on 12 development anchors after five epochs. It uses AdamW (learning rate $3\times10^{-5}$, weight decay $0.01$) and visual trajectory MSE plus $0.1$ times proprioceptive trajectory MSE. The wrong-layer control applies the frozen readout to unmodified BF16 predictions. Both use the same fixed 11 candidates and are evaluated on 80 entirely new states. One training seed is used; state-bootstrap intervals therefore condition on this fitted checkpoint and do not quantify training-seed variability. This is prospective within-project validation on disjoint states, not replication by an external implementation.

\subsection{Official high-dimensional Push-T H6}

The frozen H6 validation uses the official one-shot CEM setting: 30 iterations, 300 sequences per iteration, 10 elites, 9,000 model queries, and the returned final mean. Each H6 model action contains five 2-D simulator controls, so CEM searches 60 scalars and the plan executes 30 controls. Thirty fresh near-contact initial states use contiguous precommitted seeds with no filtering, retry, or replacement.

Every sequence queried by baseline latent-L2 CEM is retained and simulator-evaluated. GT-readout, predicted-readout, and predicted-L2 rankings on this identical 9,001-sequence trace per episode isolate fixed-trace prediction and metric headroom. The action-blind H6 readout is a \texttt{StandardScaler}+ridge model ($\alpha=0.1$), selected by five-fold grouped-development-episode MSE and fit only to true development futures. A matched-budget CEM run changes only the scorer to this readout. This scorer test was precommitted from the local study; it is \emph{not} the prediction repair that the H6 diagnosis would select. Because the scorer changes elite updates, the two adaptive traces are not candidate matched; their union is used only as a finite audit reference, never as a global action oracle.

\paragraph{Statistics.}
Reported intervals are 95\% paired nonparametric bootstrap confidence intervals over independent anchor states or episodes. No candidate-level pseudoreplication is used. Wall repair intervals are conditional on its single fitted predictor. Full protocol and artifact details appear in Appendix~\ref{app:repro}.
